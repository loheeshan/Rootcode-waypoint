WAYPOINT - DEMO LOGIN CREDENTIALS
=================================
DEMO ONLY. These accounts exist only in the demo environment started with `docker compose up`.
Do not reuse this password anywhere else.

Start the demo
--------------
1. From the project folder run:  docker compose up
2. Wait until the logs show the API and web are ready (first start can take a few minutes).

Web (open in a browser)
-----------------------
Store app        : http://localhost:3000/store
Dispatcher app   : http://localhost:3000/dispatcher
API docs         : http://localhost:8000/docs

Accounts (all use the same demo password)
-----------------------------------------
Role            App              Email                        Password
Store manager   Web (Store)      store@waypoint.demo          WaypointDemo#2026
Dispatcher      Web (Dispatcher) dispatcher@waypoint.demo     WaypointDemo#2026
Loader          Loader app       loader@waypoint.demo         WaypointDemo#2026
Driver          Driver app       driver@waypoint.demo         WaypointDemo#2026

Mobile apps (Loader and Driver)
-------------------------------
- Open the QR code / exp:// link printed in the docker compose logs with Expo Go.
- Loader app needs Expo Go for SDK 57; Driver app needs Expo Go for SDK 56.
- Android emulator API address: http://10.0.2.2:8000/api/v1
- Phone on the same Wi-Fi: http://<your computer's LAN IP>:8000/api/v1
- The Driver app asks for camera access to take the proof-of-delivery photo.

Quick check
-----------
1. Store: sign in, create an order.
2. Dispatcher: sign in, optimize today's plan, assign the driver, publish.
3. Loader: sign in, record loading for the trip, mark it ready.
4. Driver: sign in, start the trip, arrive, take the proof photo, deliver, complete.
5. Store: see the order delivered and confirm receipt.
6. Dispatcher: see the final status, exceptions and audit history.

Reset the demo data
-------------------
docker compose down -v
docker compose up
